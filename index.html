01

s01_nco · numerically controlled oscillator

先有一只干净的正弦

100 kHz

背景

NCO 不直接算 sin()。它把一个不断累加的“相位”当成地址：32 位相位累加器每来一个时钟就加上频率控制字 FTW，溢出就自然回到 0，正好对应相位绕了一整圈。

取相位的高 12 位作为地址，去查一张 4096 项的 sin/cos 表，就同时得到两路 12 位有符号样本。正弦和余弦来自同一个相位，所以它们天然正交；混频器后面需要的正是一个复本振 cos + j·sin。

频率控制字 · 输出频率 · 窗口周期数 FTW = Fout × 232 / fclk = 100 kHz × 232 / 50 MHz ≈ 8,589,934
Fout = FTW × fclk / 232 ≈ 100 kHz
每周期点数 = 50 MHz / 100 kHz = 500 点　→　8192 点里 16.384 个周期

相位每拍前进约 8.192 个表地址，所以 4096 个表项不会每一个都被采到。实际采样点落在哪里，取决于 FTW；这决定了“正弦峰值那一拍，余弦不一定正好是 0”。

这也是为什么验收判据不应该盯住某一个固定值，而应该看对采样格点不敏感的关系，例如 sin² + cos² 是否接近满幅的平方。

触发备注
这次触发点在 4096，落在 fsin=2047 的峰值上。峰值在表里只对应一个地址，能不能踩上带一点运气；更稳的写法是用阈值，例如 fsin_o >= 0x7F0，每周期会有约 19 个采样点命中。这次命中了峰值，说明触发相位有效，但它不是可复现性最好的触发策略。

02

s02_mixer · complex mixer

把频率搬到和 / 差上

50 k / 450 k

背景

混频的本质不是“把波形变复杂”，而是乘一个复本振，把频谱整体搬移。输入是复单音 ejωinn，本振是 e±jωlon，两个指数相乘，频率就变成和或差。

实验台上，输入 NCO 产生 250 kHz 的 I/Q，本振 NCO 产生 200 kHz 的 cos/sin。顶层参数 CONJ 决定本振取不取共轭：取共轭是下变频，差出 50 kHz；不取共轭是上变频，和出 450 kHz。

上变频 · CONJ = 0 (i + jq)(cos + j sin)
  = i·cos − q·sin + j(i·sin + q·cos)
下变频 · CONJ = 1 (i + jq)(cos − j sin)
  = i·cos + q·sin + j(q·cos − i·sin)

因为 I/Q 两路都在，混频后的复信号只落在一个频率上；反映到 i_out 上，就是一条幅度稳定、频率单一的正弦。如果只拿一路实信号去乘余弦，和频与差频会同时出现，波形上会看到拍频包络——这张图里没有包络，正好说明复数混频在按预期工作。

从窗口里的周期数反推输出频率 下变频：250 kHz − 200 kHz = 50 kHz　→　50 MHz / 50 kHz = 1000 点/周期　→　8192 点里 8.192 个周期
上变频：250 kHz + 200 kHz = 450 kHz　→　50 MHz / 450 kHz = 111.111 点/周期　→　8192 点里 73.728 个周期

03

s03_fir · 47-tap linear-phase low-pass

让冲激响应自己交代系数

47 taps · 4 clk

背景

FIR 的输出是输入与系数的卷积。与其看“一个正弦被滤小了多少”，不如直接送一个单点冲激：输出序列就是滤波器的冲激响应 h[k]，每一个点都能和系数表逐点对账。

这版设计是 47 抽头、Hamming 窗、归一化截止 0.15 的低通。系数用 Q1.15 表示，和恰好是 32768 = 215，所以直流增益精确为 1.0；中心抽头 9810，最小系数 −1867。通带 [0, 0.10] 纹波 0.037 dB，阻带 [0.20, 0.5] 衰减 55.7 dB。

卷积 · 定点缩放 · 冲激响应 y[n] = Σ c[k] · x[n−k]　(k = 0…46)　>>> 15
h[k] = floor( ( c[k] × 2047 + 214 ) / 215 )　输入冲激幅度 = 2047
h[23] = floor( (9810 × 2047 + 16384) / 32768 ) = 613

因为 c[k] = c[46−k]，滤波器具有线性相位，群延迟是整数 23 个采样。对称还带来一个直接好处：可以先把成对的样本相加，再乘一次系数，于是乘法器从 47 个降到 24 个。

为什么是 4 拍延迟

为了在 50 MHz 下给加法树留时序余量，设计被切成 4 级流水。每一级都在时钟沿打一拍，所以从输入被采样到 y_out 出现，正好晚 4 个采样点。

04

s04_resample · 2× halfband polyphase

换采样率，不换信息

2× · 15 mult

背景

DUC 要在混频之后把符号率抬到 DAC 速率，DDC 要反过来把 ADC 速率降下来。s04 做的是最小、最能看清结构的一步：2× 半带插值 / 抽取。它不追求任意 L/M，而是把“多相分解”在一张 61 抽头的表上拆开给你看。

2× 插值的标准做法是“零插值 + 低通”。半带的偶相系数只有中心 0.5，其余偶数抽头全为 0；所以偶相不需要乘法器，只是 x[n−15] 的纯延迟。奇相还剩 30 个抽头，利用对称性折成 15 对预加 + 乘法。61 抽头，真正要算的只有 15 个乘法。

插值 · 1 进 2 出 y_e[n] = x[n−15]
y_o[n] = (Σ o[i]·x[n−i]) ≫ 14
抽取 · 2 进 1 出 y[n] = (2¹⁴·x_e[n−15]
  + Σ o[i]·x_o[n−1−i]) ≫ 15

抽取是同一件事倒过来：偶相贡献 0.5·x_e，奇相贡献 30 个抽头。注意 x_o 的窗口整体往回挪一拍——交错信号里 x_o[n] 比 x_e[n] 晚半个采样，卷积对齐时就要多减 1。这个 −1 不是时序 bug，是抽取的相位关系。

一张表，两种用法 · 为什么 SHIFT 不同 H(z) = E(z²) + z⁻¹·O(z²)，半带的 E(z) = 0.5·z⁻¹⁵
插值要补零插值的 ×2：2·S / 2¹⁵ = S / 2¹⁴ → SHIFT = CW−2 = 14
抽取没有零插值，不需要补 2 → SHIFT = CW−1 = 15

系数是 Q1.15：奇数抽头和 16384，中心 16384，合起来正好 32768 = 1.0。通带 [0, 0.20] 纹波 0.0235 dB，阻带 [0.30, 0.5] 衰减 53.1 dB，并且满足半带的结构性质 A(f) + A(0.5−f) = 1。

为什么是 4 级流水

和 s03 的 FIR 同一套思路：先全精度算完，最后才舍入/饱和。延迟线 → 乘积寄存器 → 4 组部分和 → 组间相加 + 舍入 + 移位 + 饱和。输入到输出是 4 级流水；但 y_e 的源是 dly[15]，延迟线本身还贡献 15 个输入样本的群延迟。

    级联 43 点，峰值 1991。y_rt 在 +17..+59 出现 43 个点，峰值 +38 = 1991，关于 k=30 对称。这一条同时证明两相相位对齐、以及 interp 的 13 位输出被 decim 按 13 位接收。

别误读
ILA 的“第几个点”不是 k。imp_dbg 是组合逻辑，ILA 在它变 1 的那一拍就触发；数据要到下一拍才进 dly[0]。所以 ILA 偏移 = 输出下标 k+4（插值）/ k+8（级联）：y_e 在 +19，y_o 峰值在 +18/+19，y_rt 峰值在 +38。截图横轴是窗口内序号，不要直接把它当触发偏移。

再看一眼
1991 不是 2047，是正常的。插值再抽取整体是半带响应的平方，通带纹波会让峰值差几个 LSB；它仍然和 Python 模型逐位一致。30 DSP 是两个方向都例化的实验台；真实 DUC 只需要插值那 15 个。抽取的 IW 必须等于插值的 OW=13，这是 s05 位宽预算的第一道硬约束。

WHAT THE WAVES PROVE

四组波形，各自回答一个问题

S01 / NCO

频率与正交性都对

窗口内 16.384 个周期 → 100 kHz；sin² + cos² 全窗最大偏差 2,304，小于 4,096 判据。先有一只干净、可复现的本振，后面的混频才有意义。

S02 / MIXER

频率确实被搬走了

下变频差出 50 kHz（5 : 1），上变频和出 450 kHz（1.8 : 1）；两组 capture 各 8,191 / 8,191 点按 RTL 公式复算一致，0 LSB。

S03 / FIR

系数表逐点对上

47 点响应、4 拍流水延迟、中心 613、两端 1、关于 k=23 对称；8/8 组与 expected_h.md 逐点一致，0 LSB。

S04 / RESAMPLER

采样率换了，数据没坏

61 抽头只算 15 个乘法器；y_e 单点 2047、y_o 峰值 1298、y_rt 峰值 1991；7/7 个冲激三路输出全部逐位一致，0 LSB。

→下一步不是继续看图，而是把它们接起来。NCO 提供本振、mixer 搬频率、FIR 选带宽、resampler 换采样率；真正集成成 DUC 是 s05 的事。位宽已经是一道具体的题：mixer 输出 13 位、FIR 默认 12 位、interp 输出 13 位、decim 输出 14 位；增益预算和位宽衔接会成为第一道题。另外 s04 是两相并行接口，接 DAC 前要加 2:1 并串。

把四个零件，
接成一条回环。

前四篇各讲一个零件：NCO 产生本振、混频器搬频率、FIR 选带、半带换采样率。这一篇讲的是把它们接起来：DUC 把 500 kHz 的单音搬到 3 MHz，DDC 再把它搬回 500 kHz。算法没有变，难的是位宽、增益、本振相位和流水延迟——任何一处错，频率都可能还是对的，但整条链已经歪了。

PART ONE · 系统

一条链，两个方向

INTEGRATION

DUC：把基带搬到低 IF

DUC 的顺序是 成型 FIR → 复数混频 → 2× 半带插值。符号先经过 I/Q 两路 FIR 成型，再乘上 e+jφ 搬到 flo = 0.05 Fs，最后 2× 插值成两相，交给 DAC。

INI/Q 符号Fs · 12 位
→
FIR ×2成型滤波47 抽头 · 13 位
→
MIXER上变频CONJ=0 · 14 位
→
INTERP ×22× 插值两相 · 15 位
低 IF 约束：flo 必须落在 FIR 通带内，且 flo + 信号带宽 < 0.10 Fs。本设计 0.05 + 0.01 = 0.06 Fs。

DDC：反着走一遍

DDC 是严格逆序：2× 半带抽取 → 复数混频（下变频）→ 基带 FIR。两相输入先降到 Fs，再乘 e−jφ 搬回 0，最后用同一张 47 抽头表做信道滤波。

IN两相 I/Q2Fs · 15 位
→
DECIM ×22× 抽取抗混叠 · 16 位
→
MIXER下变频CONJ=1 · 17 位
→
FIR ×2基带信道47 抽头 · 18 位
最后饱和到 13 位：12 位符号 + 1 位余量。整条链单位增益，回环 DC 增益实测 0.9975。

为什么 FIR 一定在混频之前

这是 s05 集成时改正的一个旧猜测。最初以为“先混频把频谱搬到 IF，再用低通切带外”，但真接起来会发现：成型滤波必须在基带做。

  • 混频之后再低通，滤波器的响应是 H(f)，不是 H(f−flo)。它按低通的过渡带去削 flo 附近的信号，而不是按设计时看到的那条平坦通带。
  • flo 取得很低（0.05 Fs）时“看起来还行”，换一个 IF 就露馅。
  • 标准 DUC 就是成型（基带）→ 上变频 → 插值；DDC 反过来抽取 → 下变频 → 基带 FIR。
一句话

滤波器只认它所在的那个频率位置。成型要在基带做，抗镜像/抗混叠要在换采样率的那一级做；混频只负责搬，不负责选带。

位宽链：每一级的输出 = 下一级的输入

级DUCDDC怎么来的
输入1215DUC 输入符号 / DDC 输入 = DUC 插值输出
1FIR 13decim 16单位增益，留 1 位余量
2mixer 14mixer 17全精度乘加后舍入 + 饱和
3interp 15FIR 18半带 / 47 抽头，单位增益
输出15（两相）13（饱和）DUC 给 DAC / DDC 给基带

两个容易踩的点：

  • 中间不能截位。每一级的 OW 必须等于下一级的 IW；截回 12 位，随机信号会慢慢累积误差。
  • 14 位 mixer 是“刚好够”。2047 × 2047 × 2 >> 11 = 4092，14 位正上界 8191；15 位 interp 则留了很大余量。把 interp 的 IW 从 14 改成 13，满幅单音下测不出来——截掉的是余量位，不是有效位。

PART TWO · 上板

3 MHz 搬上去，500 kHz 搬下来

ILA

先学会看 ILA：只看周期，不看清零

ILA 的横轴是采样点，不是时间。板子的采样时钟是 50 MHz，所以：

点与时间 1 点 = 20 ns　　→　　f = 50 MHz / 一个周期的点数
4096 点窗口 = 81.92 µs　　→　　100 点/周期 = 2 µs = 500 kHz

看波形时不用管每一拍的绝对值，只数一个周期占多少点。3 MHz 的周期是 333.3 ns，正好 16.667 点；500 kHz 的周期是 2 µs，正好 100 点。两者一比就是 6:1。

看什么怎么算本例
频率50 MHz ÷ 一个周期的点数100 点 → 500 kHz；16.667 点 → 3 MHz
频率比两路周期之比100 / 16.667 = 6.0000
正交I/Q 两路的相位差−90.00°
幅度正弦峰值约 2042（满幅 2047）
纯度整窗拟合的残差 RMS约 1 LSB（−66 dBc）

DUC：下面 500 kHz，上面 3 MHz

这张图只回答三件事：

  1. 搬移成功：输出频率 3 MHz，不是 2 MHz（差频），说明混频用的是 CONJ=0 的和频；
  2. 比例正确：3 MHz : 500 kHz = 6.0000，正好 0.01 + 0.05；
  3. I/Q 正交：ie 与 qe 相位差 −90.01°，幅度都在 2042 附近，不是单路。

DDC：上面 3 MHz，下面回到 500 kHz

这张图回答的是“搬上去还能不能搬回来”：

  • di/dq 回到 500.0 kHz，周期 100.000 点，和输入单音同频；
  • di 与 dq 相位差 −90.00°，复包络纹波 0.08%；
  • 回环增益 0.9975（−0.02 dB），幅度基本守恒；
  • LED0/LED1 常亮，LED2/LED3 1 Hz 心跳——板上肉眼也能确认链路活着。

PART THREE · 集成税

两个“频率对、相位错”的坑

PHASE

LO_DLY：独立 DDC 是 14，回环是 23

DDC 混频器要拿回 DUC 混频器当时用的那个本振相位 lo[n]，再取共轭把它搬回 0。问题是数据不是“立刻”到 DDC 的：

  • 独立 DDC：数据在第 n 拍就到 DDC 输入，功能模型里需要 lo[n−10]；RTL 的延迟线长度 = 10 + 4 = 14。这个 10 是 interp/decim 在 flo 处的相位延迟，不是半带的群延迟 15。
  • 回环：DUC 的输出比 DUC 输入晚 9 拍才到 DDC，所以 DDC 的本振也要多等 9 拍：14 + 9 = 23。
相位延迟 ≠ 群延迟 功能模型：lo[n−10]　→　RTL：10 + 4 = 14（独立 DDC）
回环：14 + DUC 9 = 23（ddc_top 里的 LO_DLY_DDC）

写成 14 会怎样？频率仍然是 500 kHz，幅度也基本不变，但 I/Q 整体旋转：

差 9 个样本的相位 flo = 0.05 Fs　→　每样本 18°　→　9 × 18° = 162°

step 场景（DC 1000 混上去再混下来）会从期望的 +998 / 0 变成大约 −949 / ±308：I 路几乎反相，Q 路从 0 变成几百。看频率完全看不出来。

DDC 的 LO 下标step 输出说明
10（RTL 14）+998 / 0相位对
15（RTL 19）0 / +998差 90°
20（RTL 24）−998 / 0差 180°
板级 ILA 的盲区

回环里没有独立参考，把 23 写成 14 时，频率、幅度、正交性全都照样对，只是整条链旋转 90°。这块 ILA 证明不了绝对相位；绝对相位由 tb_duc_ddc_loopback 的逐位向量保证（step +998/0）。所以判据要分两层：ILA 看频率/幅度/正交，向量看绝对相位。

2:1 并串：phase 计数器不能自由跑

DUC 输出是两相并行的，接 1 路 DAC 前要并串。第一版写得很自然：在 clk2x 域里每个沿翻转 ph，ph=0 选偶相、ph=1 选奇相。仿真一跑，偶/奇相整体互换——频率全对，拼起来是废的。

原因不是算术，是定帧：ph 是 clk2x 域的计数器，它不知道 clk 域的“一帧”从哪开始；复位释放的时刻决定它先数到 0 还是 1。正确做法是用 clk 的上升沿给 ph 定帧：

serializer2.v用 clk 上升沿定帧
// clk2x 域：clk 上升沿后的第一个沿 = 新的一帧
clk_d <= clk;
if (clk & ~clk_d) begin
    e_r <= d_e;
    o_r <= d_o;
    d   <= d_e;      // 先出偶相
end else begin
    d   <= o_r;      // 同一帧的第二个沿出奇相
end

接收端在 negedge clk2x 采（数据眼图中间），并用同样的 clk & ~clk_d 定帧。tb_serializer2 用 32 对互不相同的值驱动，搜固定延迟后逐点比对，能同时抓“延迟错”和“偶/奇互换”。

这块没有进板级顶层：板上没有 DAC，也没有 2Fs 时钟。模块在 rtl/common/，等接 DAC 时再加 MMCM 和 2 倍时钟。

如果只记三件事

  1. 成型在基带、上变频、插值；DDC 反过来。混频后再低通，滤波器响应是 H(f) 而不是 H(f−flo)，等于用错了一条曲线。
  2. LO_DLY 不是模块固有参数，是“数据到混频器走了多久”。独立 DDC 14、回环 23；写成 14 频率仍对，但 I/Q 旋转 162°——判据是 step +998/0。
  3. ILA 证明频率/幅度/正交，逐位向量证明绝对相位。回环没有独立参考，板级波形看不出 23 和 14 的差别；那 9 拍由 tb_duc_ddc_loopback 保证。
